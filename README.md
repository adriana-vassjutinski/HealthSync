# HealthSync

## Overview
This is a minimal prototype of the HealthSync system, built for the Software Engineering 2 course. It demonstrates basic patient record management including prescriptions.

## How to run
1. Import the project into Eclipse.
2. Run the `Main.java` class.
3. The program will display patient information and associated prescriptions in the console.

## Repository structure
- `com.healthsync.model` – classes representing data models
- `com.healthsync.repository` – in-memory storage for patients
- `com.healthsync.service` – service layer managing logic
- `com.healthsync.main` – main application entry point
